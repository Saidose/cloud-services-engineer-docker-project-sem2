# Секреты

Каталог для файлов-секретов, передаваемых контейнерам через Docker Secrets (монтируются в `/run/secrets/<name>`, не попадают в образ и не задаются через ENV)

## Боевое использование

1. Замените содержимое файла настоящим секретом
2. Реальные секреты не коммитятся, не коммитьте их, в gitignore добавлены маски для игнорирования секретов используйте эти naming-conventions
3. В CI/CD секреты берутся из хранилища секретов, а не из репозитория
